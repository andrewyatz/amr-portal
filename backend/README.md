# AMR Portal Backend

FastAPI backend serving filter configuration, data records, and downloads from a DuckDB database produced by data-loader-etl

## Prerequisites

- Python 3.12+
- A DuckDB database generated by the ETL pipeline

## Setup

Install dependencies into a virtual environment:

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Configuration

Settings are loaded from a `.env` file in the `backend/` directory, or from environment variables exported to the shell.

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `DUCKDB_PATH` | Yes | — | Path to the DuckDB database file |
| `ENABLE_DATACONNECT` | No | `false` | Enable GA4GH Data Connect API endpoints |

Example `.env` file:

```
DUCKDB_PATH=/path/to/amr_release.duckdb
ENABLE_DATACONNECT=true
```

Or export directly:

```bash
export DUCKDB_PATH=/path/to/amr_release.duckdb
export ENABLE_DATACONNECT=true
```

## Running

```bash
uvicorn backend.main:app --reload
```

## API Endpoints

### Core (`/api`)

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/filters-config` | GET | Filter configuration for the frontend |
| `/api/amr-records` | POST | Query filtered data records |
| `/api/amr-records/download` | POST | Download filtered records as CSV or JSON |
| `/api/amr-records/download` | GET | Download via Base64-encoded query params |
| `/api/release` | GET | Release metadata |
| `/api/health` | GET | Health check |

### GA4GH Data Connect (`/dataconnect`) — optional

Enabled when `ENABLE_DATACONNECT=true`. See [DATACONNECT.md](DATACONNECT.md) for full details.

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/dataconnect/service-info` | GET | GA4GH service metadata |
| `/dataconnect/tables` | GET | List available tables |
| `/dataconnect/table/{name}/info` | GET | JSON Schema for a table |
| `/dataconnect/table/{name}/data` | GET | Paginated table data |
| `/dataconnect/query` | POST | Execute SELECT queries |

## Tests

```bash
TESTING=1 DUCKDB_PATH=/path/to/amr_release.duckdb python -m pytest backend/tests/ -v
```

Data Connect tests use an isolated in-memory DuckDB and do not require a real database.
